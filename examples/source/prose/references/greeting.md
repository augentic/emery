# Greeting source

The mock source documents one behaviour: GET /greeting returns the static string 'hello'. Its requirement id stays `greeting.behaviour`. A criterion id extends that id (`greeting.behaviour.body`) when the bound tree states acceptance. A brief that adds a behaviour of another concept takes a stem of its own (`throttling.limit`), and a directive prescribing a technology for it is a `decision` beside the `requirement`, never part of its id or statement.
